# caps-paper

Capabilities: Paper and files. Two screens are shown in full: Bob's old
mailbox (55) and Alice's lease renewal (30). Scans to a searchable archive
stay in Frank's day (cap 6, `inDay`), so this block does not show OCR.

## What changed and why (landing page v1)

Both screens now show real work instead of mocks.

- **Mailbox (55).** The view is the agent's actual search: the FTS5 query,
  "6 messages of 18,023", one row per message with the FTS5 `snippet()`
  highlights, and the 2021 terms row marked as the answer. Under it is a crop
  of the real PDF page 3, with the sentence marked where `pdftotext -bbox`
  places it. The reply now tells the story the mail tells: the 2019 terms
  credited half and only on return, the predecessor renegotiated after a broken
  December delivery, and the 2021 terms credit in full. The program column is
  now `SQLite FTS5, pdftotext`. notmuch has no aarch64 conda-forge build and is
  not installed on the build host, so the agent writes a small indexer, which is
  what it would do on such a host anyway. Docling was not needed for born-digital PDFs.
- **Lease (30).** The view is a redline of the lease itself: unchanged clauses
  fold into quiet lines, date-only changes (§ 4 term, signing date) into one
  line, and the four real changes are numbered with deletions and insertions
  marked. In round 6 the lease had 11 pages and diff-pdf/LibreOffice. Now it
  has 2 pages, and the comparison is `pdftotext` + `git diff --word-diff`, whose
  real output is the tool row. The four changes are the notice period, the rent
  review floor, the new signage clause and (new in this round) the deposit
  going from two to three months' rent, so "four differences" is true of the
  actual files. The reply works out what
  matters: with six months' notice, leaving at the end of 2027 means giving notice by the end of June.
- Left-hand result lines were rewritten to match. The work (Show work) has
  honest commands and trimmed true outputs.

## Assets and how they were made

`node blocks/caps-paper/assets.mjs` (set `TMPDIR` to scratch and `PROTO_WEB` to
a `web/` with Playwright) writes one file to `$ETUSIVU_ASSETS/caps-paper/`:

- `terms-2021-p3.webp`: 676×355, about 23 KB. Clause 6 of the fictional
  Clearline terms, page 3.

It also leaves the intermediate files in `$TMPDIR/caps-paper-work/`. None of them ship:

1. **PDFs** printed by Playwright Chromium (`chromium-1243`) from HTML written in
   the script: `clearline-terms-2019.pdf`, `clearline-terms-2021.pdf` (4 pages,
   two-column fine print in Instrument Sans from `design-system/fonts`, clause 6
   on page 3), and `lease-2026.pdf` and `lease-2027.pdf` (2 pages each, serif).
2. **Mailbox**: Python 3 stdlib (`mailbox`, `email`), seeded, writes
   `sales-2014-2024.mbox`: 18,023 messages, 7.2 MB, seeded filler between
   invented shops plus eight Clearline messages, two with the terms PDFs
   attached.
3. **Index**: SQLite 3.45.1 FTS5 (`porter unicode61`) holds each message, and
   each PDF attachment page by page through `pdftotext -layout` (poppler).
   Query `(glass OR clearline) AND (breakage OR broken OR damaged)`: 9 hits in 6 messages.
4. **Lease**: `pdftotext` per lease, split per clause, word-level `difflib`
   for the redline, and `git diff --no-index --word-diff=plain -U0` for the
   tool row. Both find the same changes.
5. **Picture**: `pdftoppm -r 200` page 3, then ImageMagick (`convert`):
   marker rectangles from `pdftotext -bbox` word boxes are multiplied on, the
   image is cropped to the clause in its column, and written as WebP q82.

The search rows, word diff and page text in `block.js` (`HITS`, `LEASE`,
`SEARCH_OUT`, `WORDDIFF`, `P3`) are copied from this run's `out.json`.
Re-running the script yields the same output. The PDF bytes may differ with
the Chromium version, and the text does not.

## Sources and licenses

No third-party material. Every document, message and name is fictional and
generated by `assets.mjs`. The font is Instrument Sans (OFL, already in
`design-system/fonts`). It is embedded in the generated PDF, and only the
rendered crop ships.

## Assumptions and notes for Jari

- No program claims leadership of its field, so no source quotations are needed.
- The tool durations (`1 min 12 s`, `38 s`) are plausible guesses. Indexing
  itself takes about a second on the build host.
- The lease PDF falls back to DejaVu Serif in Chromium. The lease is shown as
  an HTML redline, not as an image, so this does not show on the page.
- "Docling", "notmuch", "LibreOffice" and "diff-pdf" no longer appear in this
  block, because the work did not use them.

## Engine needs

- On desktop, opening the work scrolls the whole screen, so the view's top
  scrolls out of sight with the conversation. A view that scrolls on its own
  (or stays put) would keep the result visible while the work is open. This is
  not solved in the block.
