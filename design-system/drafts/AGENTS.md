# Designer drafts

`v1/`, `v2/` and later `vN/` directories hold the AI designer's drafts and
handoffs for each round. Keep them as references, not implementation contracts.
The production canon is [`../production-v1.md`](../production-v1.md) and the
[`../tokens/`](../tokens/) source. Give each new round its own `vN/` directory.
