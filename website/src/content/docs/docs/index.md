Open Habitat gives everyone on a team a real coding agent with its own Linux
account, used from a browser. One person sets up one Linux server; everyone
else signs in and works, with nothing to install. Each person is their own
Unix user, and native tools keep their files, credentials and conversation
histories.

- [Try it](/docs/try/): what you need and how an installation goes today.
- [Security model](/docs/security/): what separates people, and what does not.
- [Goal and user journeys](/docs/product/): what people should be able to do.
  This is the repository's `docs/product.md`, shown as it is.
- [Install and operate](/docs/operations/): the full operator guide for your
  own server, the repository's `docs/operations.md`.

The current release line is 0.1, an early pre-release published on
[GitHub Releases](https://github.com/Open-Habitat/open-habitat/releases). Formats and interfaces may still change
from one release to the next; the
[changelog](https://github.com/Open-Habitat/open-habitat/blob/main/CHANGELOG.md) says what changed. To take part, read
the [contributing guide](https://github.com/Open-Habitat/open-habitat/blob/main/CONTRIBUTING.md). Report problems
through
[GitHub Issues](https://github.com/Open-Habitat/open-habitat/issues), and
security problems through GitHub's
[private vulnerability reporting](https://github.com/Open-Habitat/open-habitat/security/advisories/new), as the
[security policy](https://github.com/Open-Habitat/open-habitat/blob/main/SECURITY.md) describes.
