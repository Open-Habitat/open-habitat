Open Habitat is a browser interface to native AI agents and workspaces on one
Linux server. Each person works as their own Unix user; native tools keep
their files, credentials and conversation histories.

- [Try it](/docs/try/): what you need and how an installation goes today.
- [Security model](/docs/security/): what separates people, and what does not.
- [Goal and user journeys](/docs/product/): what people should be able to do.
  This is the repository's `docs/product.md`, shown as it is.
- [Install and operate](/docs/operations/): the full operator guide for your
  own server, the repository's `docs/operations.md`.

The project is in pre-release. Formats and interfaces still change between
releases. Report problems through
[GitHub Issues](https://github.com/Open-Habitat/open-habitat/issues), and
security problems through GitHub's
[private vulnerability reporting](https://github.com/Open-Habitat/open-habitat/security/advisories/new).
