# Open Habitat

Open Habitat is a multi-user web host for native AI agents. A person signs in
through the browser, the gateway maps them to their own Linux user, and a
daemon running as that user runs their agents and tools exactly as they would
run over SSH.

The project is in pre-release. [TESTING.md](TESTING.md) describes how to build
and test it, and [docs/operations.md](docs/operations.md) how to operate an
installation. Report problems through GitHub Issues and security problems
through GitHub's private vulnerability reporting.
