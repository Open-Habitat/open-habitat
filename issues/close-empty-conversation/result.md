# Empty conversation Close

Close now requests a daemon action only for a browser-controlled idle conversation with no accepted or attempted sends. The daemon checks browser origin, all branches of any native history, active annotation and observable external writers before stopping and reaping its direct child; it then verifies the source again and removes only the empty native file. A detached child that inherited the ownership lock prevents removal. The browser masks the row immediately and restores it with a reason on refusal or failure. Non-browser history cannot offer an enabled Close.

`lab-close-ready-{light,phone-dark}.{png,html}` shows the available control; `lab-closed-{light,phone-dark}.{png,html}` shows the workspace after immediate Close. Each image has an adjacent static HTML snapshot from the synthetic lab. `lab-close-disabled.{png,html}` records the previous unavailable state. The draft assumes emptiness without source checks; production waits for positive host control and archive facts. These are same-UID synthetic fixtures, not a live host or a distinct-UID proof.
