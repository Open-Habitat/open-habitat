# Bounded native Pi RPC transport intermediate (not a browser controller)

At base `3a3f883`, selectively recovered the RPC parser probe from preserved `a190c535` without merging either failed branch. This branch adds a private daemon-owned direct-child RPC transport. Its one deadline covers the whole write and acknowledgement, a non-reading child returns uncertainty, an ambiguous channel is never reused, and the reader/reaper are independent of inherited stdout EOF. Closing returns boundedly and **always reports termination unknown**, including after direct-child exit: detached native tools and history are not thereby proved settled. Restart resume is explicitly denied; no process registry, known-owner proof or native settlement exists in this intermediate. It is deliberately not wired to HTTP, SSE, UI or advertised as a supported capability. The process runs at the daemon UID (root denied), with no delegated cgroup or sidecar. Service-level systemd cleanup remains the daemon stop/crash boundary, not per-controller cancellation. ADR 0003 now states that limitation.

Synthetic tests: `TMPDIR=/var/tmp .tools/go/bin/go test -race ./internal/daemon -run TestPiRPC -count=1 -v` covers a fake acknowledgement, a 25ms missing acknowledgement, 65536-byte escaped prompt against a non-reading child at 25ms, no retry on ambiguity, detached inherited stdout, and fail-closed restart resume. Pinned Pi 0.85.1 `get_state` succeeds with disposable HOME after `npm ci --prefix internal/daemon/pi-device-test --ignore-scripts --no-audit --no-fund`. No prompt was sent to a provider. These are same-UID disposable fixtures, not proof of two mapped user isolation, real daemon restart/systemd cleanup, native history settlement or live UI. The shutdown test cannot establish absence of deliberately detached native tools. Independent final-diff process/concurrency review (gpt-6-astra; gemini-3.8-flash verification) found four confirmed FIX findings: recycled process-group signal, inherited stderr holding Wait, missing/null success misclassified as rejection, and detached-holder test race. All four were corrected and regression-tested; assessment is in ignored `history/assessment-bounded-pi-rpc.{json,md}`. Claude finder invocation failed before returning a review; no opinion is attributed to it.

Still needed in this issue: known owner and single-writer fencing (including terminal TUI and restart), positive old-writer absence and native history settlement before resume, daemon stop/crash guest proof with disposable UIDs, authorization and CSRF, command ledger with uncertain status and no automatic retry, HTTP/SSE replay/backpressure, browser reconnection, production interaction and visual evidence, real-agent test with user's participation. None of the issue acceptance boxes is complete. Earlier preserved branches are untouched and there was no deployment.
