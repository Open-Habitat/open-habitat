# Settings section for risky features the person switches on with a warning

## Description

Jari 27.11.2026: Settings should have a section for risky features
("vaaralliset toiminnot"), where the person has to switch a capability on
explicitly, with a warning of what it allows. The first member is
`conversation-links-prefilled-draft` (links that open a conversation with a
prepared message).

Agreed next actions: the section is prototyped together with the links'
round 2, and a research worker inventories which existing and planned
capabilities belong in such a section in general (report in this issue).
Settings › Kokeelliset ominaisuudet (experimental) is a different axis:
maturity, not risk.
