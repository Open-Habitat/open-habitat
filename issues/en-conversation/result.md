# Result: English conversation view

## What landed

- Every user-visible Finnish string in the 23 modules this unit owns now lives
  in its own catalog in `web/src/text/` (named after the module:
  `browserConversation.ts`, `conversation.tsx`, `historyView.ts`,
  `conversationActions.ts`, `pendingConversation.tsx`, `useConversation.ts`,
  `conversationEvents.ts`, `conversationJournal.ts`, `heldMessages.ts`,
  `agentTurn.ts`, `agentInteractionControls.ts`, `fileToolCard.ts`,
  `outputBox.ts`, `piBlocks.ts`, `contextRing.ts`,
  `conversationModelDetails.ts`, `workingProgress.ts`, `recapCard.ts`,
  `fileOffer.ts`, `viewOffer.ts`, `viewPanel.ts`, `returnView.ts`,
  `piDeviceSignIn.ts`), with an English translation. Finnish output is
  unchanged.
- Hard-coded `fi-FI` number, date and time formatting in these views goes
  through `formatNumber` / `formatDate`, so English gets en-GB notation
  (`31/10/2026, 08:28:15`, `2 KB`, `50%`).
- Comparisons against displayed words now accept both languages: the quiet
  send receipts and the "connection lost" problem in `ConversationActions`
  (a receipt keeps the language it was written in), and a worker view's
  speaker label in `Conversation`.
- Module-level constants holding text became functions or catalog lookups
  (`AgentInteractionControls`' no-handler reason, `PiDeviceSignIn`'s
  outcomes, `FileOffer`'s kinds, `RecapCard`'s failure reasons).
- Browser specs (synthetic host, English browser, nothing chosen):
  `web/tests/ui-language-conversation.spec.ts` (a turn, its work, the tool
  row and the details) and `web/tests/ui-language-views.spec.ts` (view offer
  and panel on a host that offers views), both tagged
  `@ui-language-conversation`.
- English evidence at device scale factor 2 in `evidence/`: turn, details,
  file offers, file panel, recap and Pi sign-in from the synthetic lab
  (`web/lab/en-conversation-shots.mjs`); view offer and view panel from
  `ui-language-views.spec.ts` with `OH_VISUAL_CAPTURE=1` (the lab offers no
  views).

## Decisions for later review

- **"Recap" for tilannekatsaus, "Read only" for vain luku, "Agent working",
  "Worker working", "Thinking level"**: taken from the existing
  `navigation`, `recapSettings` and `models` catalogs so the same thing has
  one name.
- **Byte units in English are B / KB / MB / GB** (base 1024 as before);
  alternatives KiB/MiB are more exact but unfamiliar to customers.
- **The device-code flow's eyebrow is "Getting started"**, matching the
  onboarding frame's English.
- **"Pääagentti" is "Main agent"** in a worker's conversation, "Worker" stays
  untranslated as in the rail.
- **Technical wording softened for a customer**: "Hyväksytty agentin RPC:ssä"
  became "Accepted by the agent", "ilman daemonin kuittausta" became "until
  the server confirms". Finnish is unchanged.
- **Evidence keeps PNGs only**, as `ui-language-choice` did; the lab's HTML
  twins (≈600 KB each) are regenerated by the capture script when needed.
