# First-use Pi browser walking slice

The production browser now asks the authenticated mapped daemon for native Pi status **before** loading any snapshot. Missing/unknown status renders the existing production `PiDeviceSignIn` component. It starts and polls the session-bound daemon attempt, displays only the pinned verification page and bounded code, allows cancellation and retry, and opens the workspace shell only after a fresh native `usable` status plus a successfully validated snapshot. The browser never chooses a UID, socket or provider, handles a callback, or stores an OAuth token. Responses are size-capped and schema-validated; errors stay generic. On logout, focus, session switch, expired lease, restart or native status loss, old instructions and snapshots are cleared. Browser writes use the existing gateway Origin/CSRF policy and bind to the initiating session's CSRF; a new cookie cannot silently authorize an old action. Logout makes a best-effort cancel without claiming to undo an already completed native exchange.

The TLS browser fixture mounts real gateway/daemon handlers against the production bundle and a disposable fake Pi child under a synthetic home. Its device-code provider is not OpenAI; scenario and restart/expiry controls are test-only host endpoints, not compiled into the product. `web/tests/pi-onboarding-*.spec.ts` tests code/pending/usable, cancel, unavailable native status, expired lease, interrupted restart, expired web cookie, another session and another mapped synthetic account, direct native route denial and delayed poll/session-switch and cancel races. The fixture runs both invented accounts under **one actual UID**; it proves host-backed browser routing and redaction, not Unix separation. The earlier three-UID networkless container proof in [@gate-native-routes-on-pi](../gate-native-routes-on-pi/result.md) covers distinct-UID socket/daemon attempt isolation, not the browser journey. No real home, OpenAI account, installed live runtime, user reset, release or live-host deployment was used.
