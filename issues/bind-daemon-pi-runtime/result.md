Limits: ordinary nonroot Go tests skip the two root-owned fixture tests; they were executed separately in the disposable container. No live guest changes, credential use or host-specific deployment data were made here. A root operator must verify the installed bundle receipt and set the daemon config before activation; runtime checks are not an artifact digest verification.
