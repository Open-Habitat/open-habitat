## Decisions for review

- **Missing Pi facts:** A resolved question has no confirmed native history record; only the current pending question appears, and a vanished question is not labelled cancelled. No durable question log was created. Tool-result `is_error` drives the error badge; no exit code is inferred from bash text. Exact result truncation and total line count are not available in the safe tool projection, so the UI names its own preview boundary instead. The separate native local-command `output_truncated` flag is shown. Neither extension origin nor label target is invented.
- **Tail preview:** Bash defaults to Loppu and other tools to Alku, with a per-tool, tab-local preference. A saved result's browser preview may hold only its head. Until the bounded native read makes the tail available, selecting Loppu explicitly says the tail is not yet available and displays the loaded head; it does not pretend the head is the tail. Further reads scroll the bounded result view to the selected edge. The choice is not a persisted server setting or a new history store.
- **Settlement:** Only an observed `turn_settled` tied to a native entry gets the turn marker. Individual assistant model and stop-reason signals remain on their own message, without a fabricated aggregate. A tool call formed but not yet started says *odottaa ajoa*, not *ajossa*.
- **Older pages:** When the call arrives on an older page, a formerly standalone result becomes its child. The old result anchor resolves to the call row. This preserves the approximate reading location, though a long call disclosure can shift the exact pixel and its expansion state does not migrate.
- **Visual limits:** The draft simulates states that lack host facts. A Storybook state sheet and synthetic lab coverage exist, but no matching draft/lab **paired captures or measured parity** for this redesigned content were produced in this run; the earlier comparison's pairs are not claimed as matches. Jari's post-deployment visual review and full draft-fidelity coverage remain outstanding, not blockers to merging this deployable slice. The original draft's proposed names, line totals, error code, countdown, and resolved question rows were not adopted as host facts.
