# Katkon aikana säilyvä lukutila — tulos

Toteutusrevisio: `063e5f3584e4f3ea4858572cfa1fcb058be9d3e9`.

Saman istunnon vahvistetut työtilat, historia ja avoin keskustelu jäävät katkon aikana luettaviksi vanhentuneiksi merkittyinä. Uusia viestejä, pysäytyspyyntöjä tai keskusteluja ei lähetetä ennen tuoretta tilannekuvaa. Myöhään valmistuva historiasivu tai sisältöjatko ei lisää uutta sisältöä vanhentuneeseen näkymään. Uusinta ei toista kirjoitusta. Istunnon vanheneminen, uloskirjautuminen, tunnisteen vaihtuminen, 401/403, väärä snapshot-identiteetti ja virheellinen daemon-vastaus (502) tyhjentävät näkymän. Katkon jälkeen selain tarkistaa istunnon uudelleen ennen vanhojen tietojen näyttämistä.

Todisteet tällä revisiolla: `npm run lint --prefix web`, `npm run typecheck --prefix web`, `npm run test --prefix web` (55 testiä), `go test ./internal/gateway -count=1`, sekä `NAH_PORT_BASE=26800 TMPDIR=/var/tmp ./scripts/ci-local.sh --clean --json`: **passed, clean**, mukaan lukien 74 synteettisen HTTPS-hostin Playwright-testiä. Kohdennettu `@resilience`-sarja käsitti natiivilähteen virheen, viiveen, 500-vastauksen, katkenneen snapshot-yhteyden, pysähtyneen daemonin Pi-statusvastauksen, täytetyn historian, aktiivisen keskustelun sekä istunnon vanhenemisen. Saman välilehden identiteettivaihto ja uloskirjautuminen sisältyivät koko selainporttiin.

Riippumaton kriittinen katselmointi: claude-fable-5-1 löysi aluksi puuttuvan tarkistuksen vanhentuneeseen välilehteen palatessa sekä myöhemmin daemonin pysähdyksen ja statuskoodien erottelun puutteet. Ne korjattiin. gpt-6-astra tarkisti korjatun identiteettirajan ja viimeisen myöhäisten historiavastausten rajauksen; uusia vahvistettuja vuoto- tai kirjoituspolkuja ei löytynyt. Istunnon vaihtoa juuri kahden tarkistuksen välissä ei ajettu erillisenä ajoitustestinä: toinen tarkistus ja synteettinen istuntovaihdon testi antavat tästä eritasoista näyttöä.
