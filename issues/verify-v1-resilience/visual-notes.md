Malformed and oversize daemon responses are rejected as 502, and a foreign identity as 403, before the browser can show them. The client clears on either response. A directly malformed 200 snapshot also clears; a native-source 503 retains previously verified content. No host content is exposed. Delay shows loading before the eventual observation. `native-error` and `pi-blocked` lead to the first-use/onboarding flow, whose details are owned by that slice. Browser regression checks also cover recovery via button and the online event, authenticated expiry and same-tab identity switching in existing suites. A server that is stopped before the document loads can only show the browser's own network error; an already open tab can retry after the server comes back. This lab inspection does not establish what a real Pi restart does to running work.
