## Changes

The live progress line follows the running turn, rather than preceding the user's message. Live tool rows show the host's observed tool name and lifecycle state in the shared bordered row language. The event contract does not provide an arguments summary or a tool duration, and native history does not carry a durable tool status/timing record; those fields are omitted instead of manufactured. A request for an adapter/contract extension is needed if exact command/path and duration are required. The phone queue shares the transcript gutter. Stale verified conversations retain the uncertain-send bubble and draft, with one app-level reconnect banner and one explicit action; the duplicate conversation refresh link and main-area outage card are gone.

## Deliberate deviations from the draft

The draft shows a blank editor after an uncertain send, but the tab repository retains the unsent draft and blocks repeat sends by agreement (`design-system/production-v1.md`). A disconnected editor therefore still holds that text; no automatic resend occurs. The connection notice remains at the app level, not in a conversation-local mock. Tool command/path, elapsed time and progress timing are not invented from fixture prose or local clocks. A failed/stale authority check still disables writes and retains the last *verified* snapshot only under the established session-binding rules.
