# Result

The native-history view now uses the same `AgentHeader` icon row as a controlled conversation: status, retitle, archive and info. The host's `regenerateTitle` requires an owned controller session; its archive handler explicitly refuses archiving a session without one (`read_only_history`). Archiving and retitling are disabled with the read-only reason. Restoring a previously archived, readable native conversation is supported by the host, so the same icon row offers restore when the observation and connection are confirmed; the old separate restore button is gone. Process state remains unknown rather than inferred from readable history. The existing separate read-only status in the header is retained as a secondary indicator.

Paired synthetic-lab screenshots and offline HTML are `lab-{light,dark}-{1440,390}.{png,html}`. Compared with the draft, the read-only status chip remains present, and retitle/archive are disabled rather than enabled, because the host does not provide those capabilities for read-only native history. For an archived history the archive icon becomes Restore when the host facts allow it. The matching controlled-conversation capture is at `../new-conversation-topbar-flash/lab-light-1440.{png,html}` (and its theme/phone variants). The lab is same-UID synthetic host evidence, not a live test-server capture. Browser checks and visual approval follow the release.
