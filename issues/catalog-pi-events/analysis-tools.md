# Companion: Pi 0.85.1 tool and extension event fields

Paths prefixed `P/` refer to `internal/daemon/pi-device-test/node_modules/@earendil-works/pi-coding-agent/`, `I/` to its nested pi-ai package, `A/` to its nested pi-agent-core package. The [overview](analysis.md) explains the data model; the [session and RPC reference](analysis-types.md) defines the shared message and event shapes. These tables describe the pinned 0.85.1 installed artifacts examined on 3 October 2026; examples are illustrative anonymous JSON.

## Extension/hook events

These are delivered to extension handlers, **not** automatically broadcast as RPC/history. The complete discriminated union is `P/dist/core/extensions/types.d.ts:387-813`; hooks can mutate or block operations (`:669-677,718-724,814-849`). The main agent-event variants repeat the runtime event table in analysis-types.md; here are extension-only cases, including non-visible control hooks:

## Built-in tool kinds

All tools receive model-emitted `toolCall.arguments` as parameters; their results are `AgentToolResult<{details}>` and then `role:"toolResult"` messages (generic shapes in `A/types.d.ts:316-349`, `I/types.d.ts:330-346`). The schemas below define **arguments**; tool output `content` is text or image, `details` is additional metadata, and failure can be `isError:true`. For every tool an extension's `tool_call` and `tool_result` mirror these types (`P/dist/core/extensions/types.d.ts:678-771`). Result examples show `content` and `details` but omit generic IDs/timestamps. Sizes: all text/image/command/patch args can be large; read/bash/grep/find/ls use truncation with default 2,000 lines/50 KiB for tool output, grep lines max 500 characters (`P/dist/core/tools/truncate.d.ts:1-35`). `TruncationResult` = `{content:string,truncated:boolean,truncatedBy:"lines"|"bytes"|null,totalLines:number,totalBytes:number,outputLines:number,outputBytes:number,lastLinePartial:boolean,firstLineExceedsLimit:boolean,maxLines:number,maxBytes:number}`. A truncated bash output may have a `fullOutputPath` to a larger file (`P/dist/core/tools/bash.d.ts:14-17`).

| Tool | Arguments (required unless `?`); details; example |
|---|---|
| `read` | `{path:string,offset?:number,limit?:number}`; `ReadToolDetails:{truncation?:TruncationResult}` or undefined. Text file or image. `{"arguments":{"path":"README.md","offset":1},"result":{"content":[{"type":"text","text":"# Demo"}],"details":{}}}` (`P/dist/core/tools/read.d.ts:5-16`). |
| `bash` | `{command:string,timeout?:number}`; `BashToolDetails:{truncation?:TruncationResult,fullOutputPath?:string}` or undefined. Updates stream output; tail may be truncated. `{"arguments":{"command":"pwd"},"result":{"content":[{"type":"text","text":"/work/demo"}],"details":{}}}` (`P/dist/core/tools/bash.d.ts:6-17`). |
| `powershell` | Same argument/result types as bash, Windows shell variant; its argument and result shapes match bash. `{"arguments":{"command":"Get-Location"},"result":{"content":[{"type":"text","text":"C:\\demo"}],"details":{}}}` (`P/dist/core/tools/powershell.d.ts:1-15`). |
| `edit` | `{path:string,edits:{oldText:string,newText:string}[]}`; `EditToolDetails:{diff:string,patch:string,firstChangedLine?:number}` or undefined. Patch/diff can be large. `{"arguments":{"path":"a.txt","edits":[{"oldText":"old","newText":"new"}]},"result":{"content":[{"type":"text","text":"Updated a.txt"}],"details":{"diff":"-old\n+new","patch":"@@ -1 +1 @@\n-old\n+new"}}}` (`P/dist/core/tools/edit.d.ts:5-23`). |
| `write` | `{path:string,content:string}`; details **undefined**. `{"arguments":{"path":"new.txt","content":"hello"},"result":{"content":[{"type":"text","text":"Wrote new.txt"}]}}` (`P/dist/core/tools/write.d.ts:4-12,27`). |
| `grep` | `{pattern:string,path?:string,glob?:string,ignoreCase?:boolean,literal?:boolean,context?:number,limit?:number}`; details `{truncation?:TruncationResult,matchLimitReached?:number,linesTruncated?:boolean}` or undefined. `{"arguments":{"pattern":"TODO","glob":"*.go"},"result":{"content":[{"type":"text","text":"a.go:5:TODO"}],"details":{}}}` (`P/dist/core/tools/grep.d.ts:5-22`). |
| `find` | `{pattern:string,path?:string,limit?:number}`; details `{truncation?:TruncationResult,resultLimitReached?:number}` or undefined. `{"arguments":{"pattern":"**/*.md"},"result":{"content":[{"type":"text","text":"README.md"}],"details":{}}}` (`P/dist/core/tools/find.d.ts:8-20`). |
| `ls` | `{path?:string,limit?:number}`; details `{truncation?:TruncationResult,entryLimitReached?:number}` or undefined. `{"arguments":{"path":"src"},"result":{"content":[{"type":"text","text":"main.go"}],"details":{}}}` (`P/dist/core/tools/ls.d.ts:5-16`). |
| extension-provided named tool | Tool name `string`, input `Record<string,unknown>`, output `content:(text\|image)[],details:unknown,usage?:Usage,addedToolNames?:string[],terminate?:boolean`; no fixed set. `{"name":"test_tool","arguments":{"key":"value"}}` (`P/dist/core/extensions/types.d.ts:714-716,766-771`; `A/types.d.ts:316-330`). |

Tool availability: the installed built-in set also includes `powershell`, while the daemon's Linux runtime is not expected to use it. Built-in descriptions/parameters are conditional on active tool configuration; an extension can replace/add tool definitions (`P/dist/core/tools/index.d.ts`; `P/dist/core/extensions/types.d.ts:714-724`). The tool result text is not guaranteed to be a diff or a file path: the typed `content` and metadata identify what is available without inferring a format from the tool name.
