# Result

The delay was in the browser: `changeArchive` awaited the host's archive POST before changing anything visible, then waited for a fresh snapshot for the sidebar row to disappear. Host admission itself checks and reconciles native history and durably commits the visibility annotation, so request latency can add to this wait. The sidebar also prefers conversation-store metadata over snapshot agents, which can lag even after the response. The client now masks the row immediately after confirmation in both the workspace rail and return list, holds the mask across stale snapshots, and clears it on definite host confirmation or failure. The success notice is shown only after the host replies; a refusal or uncertain outcome restores the row and displays a warning. A synchronous in-flight guard prevents duplicate archive writes. Nothing is claimed archived while the POST is pending.

A host-backed synthetic Playwright test holds the archive POST and checks immediate removal, no premature success message, rollback after refusal, and continued absence after success.
