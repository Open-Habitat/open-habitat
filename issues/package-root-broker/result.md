## Public contract and required private follow-up

- The only production entrypoint is `native-agent-host broker exec` under root. No arbitrary FD, config override, network listener, OAuth credential or token path: `LISTEN_PID` must match this process, `LISTEN_FDS=1`, `LISTEN_FDNAMES=broker`; descriptor 3 is the single inherited AF_UNIX socket. `/run/native-agent-host/broker.sock` must be a root-owned mode-0660 socket with the **configured** gateway GID. Its parent `/run/native-agent-host` must be root:gateway mode 0750; no symlinks or unsafe parents. `Server` checks kernel SO_PEERCRED against the configured gateway UID. Missing `Writer.Handle` denies rather than evaluating state as a transport handler. Bounded request context flows into the writer.
- Fleetrepo `native-agent-hetzner-jit-broker` must supply the root-only, root-owned `0700` `/var/lib/native-agent-host/broker` and regular `0600` `broker.json`, `allowlist.json`, `bindings.json`, `head.json` with no symlinks. `broker.json` has exactly `version:1`, `gateway_uid`, `gateway_gid`, `uid_min`, `uid_max`, `state_dir:"/var/lib/native-agent-host/broker"`. UID/GID >=1000; UID max <=60000, max-min <=4095; gateway UID and GID outside range. The allowlist has version/epoch/approved numeric IDs; bindings have version/generation/immutable ID-to-UID/name mappings; head has version/epoch/generation. Fleetrepo must approve actual numeric IDs, reserve a collision-free UID/GID range, seed monotonic ledger/high-water and recovery policy, coordinate with existing offline 21004..21031 assignments, and retain inert alice/bob without adoption/deletion. The synthetic guest's 22010..22011 range is **not** an operator-approved pool.
- Before starting **any** broker socket, Fleetrepo must create and verify `/run/native-agent-host` and its ownership/mode after each reboot, keep gateway and broker UID/GID stable, provide boot ordering that cannot expose the socket before preparation, review packaged socket/service and any drop-ins, and provide an operator stop/inspect path for pending journal, drift or revocation. The public templates are inactive package content, not a declaration of a boot-time ACL repair service. `Writer.Startup` checks all committed bindings, pending/next files, epoch/generation and NSS/ACL/unit drift and refuses startup rather than repairing it. The package verifier does not attest installed host drop-ins or active unit state.
- The existing Fleetrepo issue is open, not implemented. Its separately reviewed landed public contract prerequisite is now this package. `@prove-jit-guest-isolation` is the **local** subsequent owner for integrating reviewed Fleetrepo declarations with two *newly allocated* UIDs, systemd, negative cross-UID routes, reboot and revocation in a private disposable guest; dynamic gateway and native-gh handoff issues and the human login-pilot gate remain separate. Neither that guest proof nor live first login, real GitHub credentials, ingress, host-key trust, actual host activation or deployed isolation is claimed here. No Fleetrepo mutation or host action was made.
