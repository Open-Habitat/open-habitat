# Result

Implemented at `7c1a32e` (after lifecycle commit `b7b6d80`). Native `~/src` discovery now reads batches of 512 entries until EOF; files do not count as workspaces and all directories are classified. A read failure marks the observation partial, and inaccessible entries are not treated as absent. Clone destination and checkout observation scan all immediate names; a case-insensitive conflict in a later batch blocks the write. Snapshots accept up to 16 MiB, the gateway buffers up to 32 MiB, and the browser accepts up to 16 MiB; a response exceeding the bound fails explicitly rather than being truncated or treated as absence. On a partial observation, confirmed workspaces remain selectable and the browser displays its incomplete-observation warning. Root navigation to the first visible workspace under a partial observation is intentional; the workspace detail also shows that warning.

## Review and limits

Independent final-diff clone-safety review by `claude-fable-5-1` inspected the scan, clone and checkout paths, `ReadDir` EOF/error semantics, shared descriptor offsets, source checks and transport caps, and found no concrete defect. It noted the deliberate root redirect under partial source and that the browser test proves acceptance of >1 MiB, not rejection above 16 MiB. Exact-name `Mkdirat` collisions are still blocked; externally created case-variant names between the complete scan and `Mkdirat` remain a native filesystem race, as before. No model finding warranted an issue.

A snapshot exceeding 16 MiB still returns an explicit failure, not a partial paginated list; collections of this magnitude are not covered by this task's tests and would need paginated snapshot delivery. The synthetic same-UID host does not prove kernel-UID isolation, live GitHub behavior, or filesystem faults arising during `getdents` beyond the injected per-entry denial. The standalone full Go package run before installing the pinned Pi helper failed two Pi-device tests with `unknown` status; the clean gate installed the helper and passed the full race suite. An initial web lint pass and first focused browser assertion also failed during development, were corrected, and passed on the committed tree.
