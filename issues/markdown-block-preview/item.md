## Description

Implementation of Jari's decision on `proto-markdown-block-preview` (round 2,
**1 Paikallaan**, 8.11.2026). The prototype is the specification:
`design-system/prototypes/rounds/2026-11-06-md-lohkon-esikatselu-2/` and
