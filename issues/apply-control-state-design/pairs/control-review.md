## Deviations and gaps

**Recorded with Jari:** `design-system/design.md` and `issues/design-control-states/design-package/HANDOFF.md` require a visible reason only when a block is unclear. The designer sheet's universal reason below every disabled control is deliberately *not* reproduced for an empty send. Nor do we treat the sheet's closed agent and new/seen attention examples as production facts: `confirmed_exited` is not deliberate closure, and there is no shared visited-event marker. A returned agent with a live native process but no confirmed turn is not labelled working. These are behavioral reconciliations, not claims of pixel parity.

**Unresolved:** The button sheet contains family-specific disabled/pending/field/menu/selection examples that the present Storybook matrix does not pair control-for-control. The design sheet's compact multi-column grids and production's wrapped matrix use different content and widths, so their dimensions are not equivalent. The draft return has synthetic attention, waiting and closure facts unavailable in the current snapshot; the lab cannot reproduce its exact history or grouping. The production return still groups by positive process observation rather than confirmed turn activity, and marks the turn unknown. The header and sidebar can show uncertainty/read-only but lack a shared attention marker and positive closure fact. Operation and capability labels share a compact visual slot in the rail; a screen reader hears both, but simultaneous visual display is incomplete. Designer comparison has not established every primitive state or the complete agent-state matrix. Jari has not given a visual verdict.

`report.md` and `report.json` were produced by the repository's `measure-fidelity.mjs` on the committed implementation. They cover **16 onboarding pairs, not the controls or return view**; the report records 79 unmapped/reproduction gaps and does not upgrade these illustrative screenshot pairs to measured equivalence. The earlier [baseline comparison](../../compare-draft-fidelity/pairs/report.md) at `eda6cba` covered those same onboarding states (16 pairs, 182 unresolved differences, 79 inventory gaps). Neither baseline nor this rerun is a before/after metric for the control design. A valid measurement needs matched fixture contents and landmark mappings for control and agent-state cases.
