# Typed Pi events — completion evidence

Pi's native session is the durable conversation; the browser now receives ordered typed previews, bounded selectable block content and provisional typed journal updates. Persisted entries supersede provisional fragments when Pi saves a turn. The gateway authenticates and forwards to the mapped user's daemon; the daemon reopens the native file and validates active ancestry, revision, UID and bounds before a selected block read. No full-text history fallback or secondary conversation store remains. The presentation here is provisional: @design-pi-event-blocks owns the final design.

## Catalogue accounting (pinned Pi 0.85.1)

The names and distinctions below correspond to `../catalog-pi-events/analysis-types.md` and `analysis-tools.md`. “Selected” means a bounded owner-initiated native block read, not a history-page or journal disclosure. Unknown payloads never pass through the fallback.

| Catalogue item | Browser data, internal role or exclusion |
| --- | --- |
| Session `message`: user text/images | Ordered text previews and image markers; selected text and supported MIME image data. |
| Session `message`: assistant text, thinking, toolCall | Ordered typed blocks, model/usage/stop reason; thinking redaction marker without redacted text or signature; tool ID/name and selected arguments. Long visible text/thinking is selectable. |
| Session `message`: toolResult | Call ID/name, error state and typed text/image blocks; selected full result. Arbitrary details excluded because they may contain credentials. |
| Session `message`: bashExecution | Distinct command and output blocks, exit/cancel/truncation/context-exclusion state; selected full command/output. Not a model tool. `fullOutputPath` is not displayed. |
| Session `message`: custom and `custom_message` | `display:true` extension content projected and selectable; `display:false` omitted. Arbitrary `details` excluded. |
| Runtime `branchSummary`, `compactionSummary`; saved `branch_summary`, `compaction` | Saved summaries have distinct types with selected summary blocks and available usage; runtime projections are not duplicate rows. `details` excluded. |
| `thinking_level_change`, `model_change`, `session_info`, `label` | Typed saved session markers; live name/thinking changes appear as provisional markers. |
| Session `custom` | Internal extension state, not conversation content; `data` excluded. |
| Assistant/provider response ID, diagnostics, deferred, errorMessage, thinking signature, rawStopReason | Excluded: unchecked provider internals can expose credentials, and signatures are not readable thinking. Safe stop reason and usage retained. |
| Images of unsupported MIME and unknown native blocks/entries | Type-only or inert placeholder; no unchecked bytes or raw payload. |
| `message_update` text/thinking/toolcall delta and toolcall end | Typed indexed provisional updates, coalesced by type/index; redacted or unverifiable thinking is suppressed. Final native entry supersedes the tail. |
| `tool_execution_start/update/end` | Bounded text-only preview, argument preview, state and call ID; progress joins its call; images/metadata omitted live. Selected native result supplies full content. |
| `bash_execution_update` | Coalesced provisional local-command output, separate from tool progress; saved `bashExecution` replaces it. |
| `agent_start`, `turn_start/end`, `agent_end`, `agent_settled`; `message_start/end`; `entry_appended` | Lifecycle/activity and history reconciliation, not additional message rows. Error/abort state from assistant `message_end`; `message_start` itself is internal. `agent_end` is not final settlement when retry can follow. |
| `queue_update` | Existing dedicated steering/follow-up queue state, not conversation content. |
| `compaction_start/end`, auto-retry and summarization-retry events | Bounded provisional transition/retry status; raw result/error objects and error strings excluded. |
| `session_info_changed`, `thinking_level_changed` | Provisional typed markers; persisted entries remain authoritative. |
| RPC `prompt`, `steer`, `follow_up`, `abort`, queue/session/model/thinking/retry/bash/tree/history/stat/export commands and response envelopes | Commands, control and acknowledgements are internal controller traffic, not history. Existing control UI handles its own scope; an ACK never means turn completed. No raw RPC response is displayed as a block. |
| Extension UI `select`, `confirm`, `input`, `editor` | Existing incoming-question presentation; answer/cancel controls remain @build-agent-control scope. |
| Extension UI `notify`, `setStatus`, `setWidget` | Bounded visible provisional event; status/widget replace or clear by key. |
| Extension UI `setTitle`, `set_editor_text` | UI mutation requests, not conversation blocks; excluded. |
| Extension hooks: session/resource/context/provider, agent/message/tool, input/bash, model, prompt and UI lifecycle | Internal callbacks, not additional RPC conversation data; especially provider headers, payloads, injected system prompt, tool inputs and arbitrary extension data must not be forwarded as unchecked UI content. Visible messages/results from these hooks appear only when Pi publishes them through its regular saved/live surfaces. |
| Built-in/extension tools: read, bash, powershell, edit, write, grep, find, ls and arbitrary names | Uniform call ID/name, selected arguments and result text/images; no per-tool special handling or raw tool-specific details/diffs/patch metadata, which may be large or sensitive. |

## Synthetic verification and limits

The implementation landed in slices: initial typed history (`3af8999`, harvested as `df708597`), typed thinking (`a73b3eb`, `ca816e4`), bounded block reads (`6c9d0be`, `6bda850`, `e0a626c`), and live tool/lifecycle events (`c8f5299`, `c6e619a`, harvested as `72b3958`). Each slice's independent review repaired concrete defects: hidden/unknown leaks and continuation usability, missing SSE subscription, saved-result/image/read duplication, entry page budgets, output-tail growth and content-index reuse. Previous passing clean gates are documented in the commit history and earlier result revisions; the latest pre-final gate passed on `72b3958` (`/var/tmp/nah-typed-live-harvest-gate.log`: 86 unit, 73 component, 122 browser E2E, 13 accessibility, Go/contracts, packaging).

Go projection and content-read tests cover ordered blocks, redaction and hidden extensions, tool association, selected images/arguments/summaries, large UTF-8 and image paging, stale file revision and branch selection, metadata-rich history budgets, live delta coalescing and lifecycle signals. Browser unit/component tests cover replacement by native history, bounded selection, unknown fallback, saved command and tool state. Host-backed synthetic browser tests use the real controller, fake Pi, mapped lab identity and browser; they check typed provisional-to-saved convergence, reconnect, warm return, paging/reading position and journal gap recovery without real credentials. Capture files in this directory are synthetic lab PNG/HTML pairs, **not reviewed by Jari**; their appearance is not a design approval.

The final host-backed typed journey uses `pi-typed` on the real synthetic controller: indexed thinking and a tool-call argument delta appear while fake Pi runs, then a saved assistant/tool-result/final response replaces provisional rows. It reloads the saved blocks, injects a skipped `assistant.thinking.delta` journal sequence and checks recovery rather than rendering the forged fragment, then returns from a warm workspace switch. Earlier `native-history.spec.ts` covers 25-entry paging and older-page scroll anchoring; `lab-conversation.spec.ts` also covers fresh replies over multiple pages and expired journal cursors. These are separate synthetic scenarios, not a claim that one Pi session has >25 typed entries. Four static pairs are `typed-provisional-{desktop,phone}-{light,dark}.{png,html}`. Their HTML is inert and self-contained; all are **unreviewed by Jari**.

The whole-issue critical review checked authorization/privacy, concurrent journal operation and history/live convergence. Finder `claude-fable-5-1` found no reachable privacy bypass; verifier `gpt-6-astra` checked five candidates against the callers. Four were confirmed and fixed in `1cccc27`: oversized local command chunks no longer flood the journal with invalidations; repeated tool-call content indexes now have unique provisional row IDs; ordinary large argument/result preview pairs fit one bounded tail frame; and a cached older settlement cannot erase a newer turn when status refresh fails. Focused Go/browser regressions cover each. The fifth candidate, dropping revision-key invalidation to keep expanded blocks across a native file change, was rejected: the native file hash is the block-read authority, and retaining loaded content against an obsolete hash would display stale bytes. No review residual merits a new issue. Ignored local records: `history/review-typed-pi-whole.md` and `history/assessment-typed-pi-whole.{json,md}`. The optional model-performance corpus write failed on the known alder SSH-to-self publickey problem; both review responses and assessment were complete.

**Final clean gate:** `TMPDIR=/var/tmp/nah-typed-final/gate NAH_PORT_BASE=14000 NPM_CONFIG_OFFLINE=true ./scripts/ci-local.sh --clean --json` passed on committed candidate `b421bc3` with a clean tree. It ran 87 web unit and 73 component tests, 122 built-host browser cases and 14 synthetic lab journeys (including the new typed convergence/recovery test), Go race tests, generated-contract checks, documentation/plan validators, VM recipe self-test, packaging/reproducibility and final checks. Log: `/var/tmp/nah-typed-final/gate-third.log`. A first attempt was deliberately interrupted at the browser phase to check the relationship between the journal frame cap and browser event bounds. That interruption left this worktree's synthetic browser-host and Vite listeners on ports 14000/14009; the next clean retry stopped at the occupied-port preflight. Both listeners were verified by cwd/command and stopped before the passing run. Neither partial attempt is counted as a pass. Evidence-only result and issue closure updates did not rerun the full gate; runnable code and packaged inputs are unchanged.

This does not establish real-provider event timing/content, live deployment, or distinct kernel-UID isolation. The synthetic host uses same-UID sockets. No personal Pi/OpenAI login, real history or Jari's browser was used. Jari has **not reviewed** the four screenshot pairs; final visual design belongs to @design-pi-event-blocks.
