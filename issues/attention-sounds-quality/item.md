# Attention sounds are not yet as good as a reference system sound (e.g. Apple Glass)

## Description

Jari 28.11.2026: feedback on Open Habitat's attention sounds: they are not yet
as good as Apple's basic "Glass" sound. Study the waveform and character of
such a reference sound against ours, find what is wrong with ours, and improve
them in a prototype round. (Key/navigation sounds, `key-sounds`, are not part
of this.)
