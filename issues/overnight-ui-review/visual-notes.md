# Synteettinen uudelleenkuvaus — ei vielä Jarin tarkistama

Kaikki 21 aamun katselmuksen näkymää kuvattiin uudelleen nykyisestä paikallisesta
laboratoriosta. Jokaisella näkymällä on täyden sivun PNG ja staattinen HTML
`pages/`-kansiossa. HTML säilyttää rakenteen mutta ei toimi käyttöliittymänä.
Alkuperäiset AVIF-kuvat jäivät `images/`-kansioon vertailua varten.

Ennen: AVIF-kuva ilman offline-tarkasteltavaa rakennetta.
Jälkeen: vierekkäinen PNG/HTML-pari, jonka verkko- ja skriptiriippumattomuus
on testattu. Kuvia ei ole vielä hyväksytty visuaalisessa katselmuksessa.
