# Phase 2B3b: read-only mapped snapshot route

The authenticated gateway now handles exact `GET /api/v1/snapshot` over TLS after session expiry and fixed-mapping checks. It constructs one new HTTP/1.1 request over the mapped UDS (never cloning browser headers), verifies the kernel peer UID on the connected descriptor, accepts only a bounded, exact-length 200 JSON response, and returns redacted failures without a cross-user retry, proxy, redirect or fallback. No browser-provided identity, UID, path or socket is forwarded. The daemon mounts snapshot beside health and native credential handoff on the one guarded listener. Its peer context and strict identity/display pair must match the trusted daemon mapping. A fresh bounded descriptor-based discovery supplies immediate directories; missing, empty, partial and error stay distinct. Unannotated IDs are deterministic subject-scoped hashes of names; accepted annotation IDs are retained. Colliding IDs fail closed. Ordering follows discovery's sorted names. Metadata, Git hints and filesystem facts stay separately represented; Git hints do not prove repository integrity. Error and uncertain entries do not become confirmed filesystem presences. No paths, native histories or process claims are synthesized. Snapshot IDs mark individual observations; one daemon incarnation supplies a zero event watermark and empty bounded command ledger while writes and stream are unavailable.

## Focused security review

Reviewed session-to-mapping equality, unknown/expired sessions, Host/TLS/path/query/method, browser routing/header stripping, single dial with connected peer UID, response status/framing/size/EOF, daemon peer context and mapping mismatch, bounded discovery, ID derivation and schema truth. A deliberately empty new outbound request prevents browser hop-by-hop headers, cookies and forwarded fields from crossing the gateway. Failed peer and malformed response return only a generic public error. Native response bytes are not logged or JSON-inspected by the gateway. Tests use disposable directories and current-UID AF_UNIX listeners; the two real systemd UIDs and socket ownership remain phase 2C work. No real home or credential was touched.
