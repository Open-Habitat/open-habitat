# Read-only login-to-workspace slice — implementation evidence

Product revision: `709b6080de4ca01e19a37ed666cdfd9916e365d7` (later evidence-only commit changes no product behavior). Status: **testing**, review requested, not approved or closed. This is the first browser-visible slice, not the full Pi/agent MVP.

## Delivered

Phase 1 built the gateway OAuth state, PKCE S256, fixed numeric identity mapping, session, CSRF and single native-token handoff. Phase 2 added one peer-guarded Unix socket per mapped daemon, native `gh` HTTPS adapter/keyring metadata attestation, descriptor-rooted immediate-directory discovery and the bounded HTTP/1.1 snapshot route. The [two-UID VM product proof](./phase-2-native.md) at committed revision `da413270c3cb149373415908d1d3cb02db2eb461` booted systemd and demonstrated A/B isolation, routing and credential boundaries with guest-local synthetic users; see its exact QEMU command/results and rollback. This phase adds a production React + Redux Toolkit + React Router browser route, canonical JSON Schema 2020-12 boundary validation and read-only navigation using the same catalog components, with browser checks and [inline AVIF evidence](./visual-acceptance.md).

The gateway binds every returned snapshot's identity and provider account to its fixed authenticated mapping before forwarding bytes. The browser bounds reads at 64 KiB, decodes strict UTF-8, validates the complete v1 snapshot, aborts superseded requests and removes previous identity data on 401, source failure, contract violation, identity swap or logout. It never selects a Unix user or repeats a write. `/` selects the first visible source-confirmed workspace; `/workspaces` selects none; a missing deep link distinguishes source-confirmed absence from unknown/partial source. The rail gives separate source, Git-hint and annotation facts, search/no-results, refresh, and read-only mutation state. Authentication callback errors return browser users to generic recoverable login, never leak tokens/paths, and only safe same-origin UI paths can be pending-flow return targets. Web logout uses `/auth/session` CSRF and exact Origin with one POST; native `gh` remains connected. There is no native-disconnect UI.

The original foundation bootstrap/EmptyWorkspace and foundation ConnectionBanner were retired; the production `AppShell`, `ConnectionBanner`, `WorkspaceRail`, `WorkspaceSection`, `NavLink`, `StatusMark`, `InlineNotice`, `Button` and shared tokens remain the UI implementation. Design-catalog Vite fixtures remain test-only and are eliminated from the production build.

## Final focused security and accessibility review

Inspected browser content boundary, schema/size/UTF-8/identity matching, stale and cross-user Redux state, OAuth state/PKCE and return URL parsing, browser routing headers stripped by the gateway, React text escaping (no HTML injection), CSRF/Origin/logout, fixture/build separation, browser storage, screenshot leakage, keyboard focus and state truth. Confirmed and corrected three issues during this phase: the old `transport.Sink` disposable test-path seam followed a symlink (now Lstat-rejected, focused race test green); an error callback had no browser recovery surface (same-origin generic return without creating a session, with negative return tests); and a daemon response with a foreign account could be contract-valid and still reach the browser (gateway now denies a mismatched binding; fake UDS and host-browser negative tests green). A confirmed-empty/deep-link decision initially treated unknown **Git metadata** as unknown **filesystem presence**; corrected to use filesystem/source facts only. A filter previously influenced `/`'s canonical selection; corrected to use the first visible item independent of the filter. React's text rendering is safe for source names; no `dangerouslySetInnerHTML`, local/session storage, browser bearer tokens, provider details, absolute home paths, or native credentials are displayed. AVIF files are synthetic text only, have no EXIF, and were scanned for home/token/secret markers. No known confirmed review finding remains outstanding.

Axe found no serious or critical violations in login, ready, empty, missing, error, partial and design catalog states; browser tests check semantic links/disclosures, skip-target focus, light/dark catalog, reduced motion and 200% page width. Screenshots are not a substitute for assertions. Workspace rail scroll remains independent on narrow/zoom layouts; no mobile acceptance is claimed.

## Limits and rollback

Host browser tests use current-UID processes and simulated distinct mapped peer UIDs. Their `/fixture/` controls are standalone test-only routes. The VM supplies the separate actual-UID/systemd guarantee. No real GitHub consent, native keyring on target, real user home, deployed Alder service, Pi history/agent control, SSE, write or reconnect stream is asserted. Daemon disconnect has no cached stale data; it shows a recoverable error and needs a deliberate refresh. Google is not configured. Binary build size with AJV is above Vite's 500 KiB warning; it is not a production functional failure but is a future performance consideration. No host mutation occurred. Rollback this slice by reverting its product commit; the previous foundation screen can be restored from Git and phase-1/2 Go binary changes remain individually revertible. The product is not deployed; no machine rollback command is needed. Jari must explicitly review the evidence and record the decision before dependent UI work proceeds.
