# Phase 2B1: native GitHub CLI adapter (not workspace delivery)

The daemon now has an explicit `NewNativeHandoff` constructor binding the trusted mapped home/subject to the HTTP/1.1 transport consumer. `internal/nativegh` runs `gh auth login --hostname github.com --with-token --git-protocol https` with the transient handoff only on stdin, then `gh auth setup-git --hostname github.com`. It reobserves `gh auth status`, numeric ID through `gh api user`, HTTPS Git protocol, the installed Git helper configuration and an ordinary `git credential fill` (output discarded). Only a verified usable install acknowledges the handoff. Already-correct state is reobserved rather than assumed. A failed or wrong-identity install attempts local logout using only a validated observed login and reports partial state if cleanup fails.

Storage is checked by opening user-owned directories and the protected file through `openat`/`O_NOFOLLOW` and `fstat` with exact permissions and a token-field marker. Keyring is never inferred from absent plaintext: an independently trusted positive keyring attestation is required. The production constructor does **not** provide such an attestor, so a keyring-only install currently fails closed rather than incorrectly claiming success. This is a remaining 2B2 integration requirement before host use. Caller-supplied runner/evidence tests exercise keyring results without invoking a live credential store. The process executor uses fixed argv, a minimal non-interactive environment, bounded outputs/timeouts and process-group cleanup; child output/errors are never returned. The separate `Disconnect` operation requires both fresh-auth and confirmation booleans, logs out the verified login, checks status absence and inert Git helper, and explicitly reports that local logout does not revoke the GitHub OAuth grant. It has no browser route.

## Focused security review

Inspected stdin-only secret channel, environment inheritance, child output, failure redaction, process-group timeouts, numeric JSON ID parsing, safe logout login characters, symlink/ownership/permission checks on config, plaintext/keyring attestation, helper probe output, and local-versus-remote revocation. Corrected a race between process start and timeout handling found by `-race`; switched file token marker inspection from an immutable string copy to a cleared byte buffer. Open descriptor checks narrow pathname TOCTOU but cannot make a concurrently modified credential file immutable; live keyring proof is deliberately withheld. No real `gh`, GitHub account, real home or systemd unit was used.
