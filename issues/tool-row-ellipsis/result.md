# Result — tool-row-ellipsis

Production tool headers now give the tool name non-shrinking space and constrain the target to a single ellipsized line. `ToolRow` uses the first line of a multi-line target. The Pi tool wrapper has a definite width: without it, a long target made the row 700px wide on a 390px phone even after the target itself was clipped. The change is shared by live and saved rows.

Synthetic-lab comparisons: `lab-{1440,390}-{light,dark}-{command,multiline,path}.{png,html}` are screenshot/static-HTML pairs; `draft-…png` is the corresponding local design draft. The long target values were invented and injected into the lab header because the fake Pi's saved `$ ls` call does not always supply a header target. For the multiline capture, the displayed value is its first line (the full multi-line value is covered by the component test). No real host or personal data was captured.

Remaining differences: production headers are about 43px tall at phone width versus 35px in the draft; production uses its existing larger disclosure spacing, status icon and surface colors. The lab fake Pi's actual command is `$ ls`, while the draft shows a different sample command, so the screenshots compare the shared header rule rather than command content. No change to those separate visual decisions was made.

Validation: `./scripts/test-focused.sh --area web` passed (111 unit, 97 component tests); `PLAYWRIGHT_BROWSERS_PATH=$HOME/.cache/ms-playwright OH_PORT_BASE=14900 ./scripts/test-focused.sh --area browser --spec browser-conversation.spec.ts` passed (61), `--spec lab-conversation.spec.ts` passed (12), and `--spec shell-accessibility.spec.ts` passed (3). The conversation spec checks desktop and phone geometry in live and reloaded history; its existing axe assertion checks the expanded bash card. These checks exercise synthetic hosts, not a live deployment. Focused self-review was sufficient for a CSS/markup fix to an accepted design; the first phone capture exposed the wrapper-width issue and prompted its correction. Visual approval remains after release.
