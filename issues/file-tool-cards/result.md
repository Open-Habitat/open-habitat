# Result

Read/write/edit now show counts in the closed row, file paths when the validated native arguments provide them, an output box for read/write, and a line diff for edit. Paired removed/added lines mark changed words and carry spoken removed/added labels. The command's copy button sits beside the command, independent of output copy.

The installed Pi 0.85.1 supplies edit replacements in `edits[]` and returns a success sentence; its patch is in private `details`, which the browser contract does not expose. Production computes the line diff from each validated replacement and separates multiple edits, with summed counts. A native unified diff, if one is present in a tool result, takes precedence, as requested; the older single-replacement shape remains a fallback for old history. Without replacement text, copy explicitly says “Kopioi diffi” rather than claiming to copy a complete new file. Native history fetches full readable argument/result blocks, with the existing 64 MiB reading cap. A read continuation note is separate from file lines, and failed tools show their native error instead of a success count.
