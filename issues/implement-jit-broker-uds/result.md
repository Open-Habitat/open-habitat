# Broker UDS transport result

Walking slice: `internal/provision/transport_linux.go` provides a Linux inherited-FD server and Unix client. The server requires exactly one pre-opened listening AF_UNIX SOCK_STREAM FD, an exact configured bound pathname, owner match on FD and socket pathname, and no world permissions on the socket pathname. It does not create or unlink a listener. Each connection checks SO_PEERCRED against a fixed configured gateway UID before parsing a four-byte length-prefixed v1 request. A single request and EOF are required before the handler runs; replies likewise require a single bounded frame and EOF before the client accepts them. The per-connection deadline is two seconds; the client honors shorter context deadlines and cancellation. Neither peer identity nor a route is accepted from request metadata. No transport logging includes candidate names or credentials.

The production default (nil handler) always returns `state_unavailable`, even when a binding exists. The injected handler used by tests is **not** an account writer. `Store.Evaluate` must not be connected as the default handler: it can return a committed binding without NSS, home, socket ACL, unit, or writer-lock drift checks. The next privilege seam is an independently reviewed root-only writer with a lock spanning state reads, journal and commit, NSS/resource validation and recovery, followed by verified routing and session revocation integration. This slice does not provision accounts, activate units, handle OAuth tokens, expose HTTP/TCP/CLI, or connect the gateway.

Hermetic tests exercise inherited-FD rejection, allowed and wrong gateway/broker peer credentials, default denial, duplicate/extra/truncated/oversized/unknown wire rejection, client cancellation, expired deadlines, stalled server reads and reconnect; existing provision tests cover corrupt and pending state. The socket fixture is created under a temporary directory and runs with the test UID, not systemd/root. These tests do **not** prove guest cross-UID access controls, production root-owned socket units/path traversal, actual NSS drift, account mutations, gateway session revocation, Fleetrepo convergence, live OAuth or credential handoff. No guest, Fleetrepo, cloud, SOPS or GitHub actions were run.
