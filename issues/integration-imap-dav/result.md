# Result

Implemented IMAP + optional SMTP in himalaya and CalDAV/CardDAV via native curl, with separate endpoint/account cards so different DAV URLs and credentials work. SMTP uses the IMAP account's username/app password, TLS or STARTTLS; omitting SMTP keeps draft-only mail. Multiple accounts, password renewal, live status, removal and personal-data agent guidance all use the tools' own configurations. No connection registry, credential service, listener or local calendar/contact database was added.

Curl was chosen because its native config and PROPFIND/REPORT/GET/PUT/DELETE support suffice for agent use without another daemon or sync database. Configs are private, under catalog-owned directories in the person's home; checks disable default .curlrc, discard bodies/stderr, never follow redirects and pass passwords only through stdin/native files. Config publication is complete-before-visible. DAV URL errors return a fixed 422 without forwarding credentials.
