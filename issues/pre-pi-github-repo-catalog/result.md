# Pre-Pi GitHub repository catalog

The authenticated gateway has one read-only pre-Pi listing route: `GET /api/v1/onboarding/github/repos?page=1..100&limit=1..50`. It rechecks the broker, dials the mapped daemon socket and reconstructs a validated allowlisted response. The daemon checks its trusted peer and immutable subject binding, runs `gh api --method GET /user` to bind installed native authorization to that subject, then queries `/user/repos` with owner, collaborator and organization_member affiliations. It neither accepts a browser token/owner nor reads workspaces or Pi history. Existing snapshot/history/conversation mounts stay behind their Pi gate. Commands inherit no server secrets, have bounded stdout and deadline, discard stderr and kill child process groups on cancellation. Responses are no-store; native failures return fixed errors.
