# Result: authorize a gateway session once

Implemented at `5199976`: callback `ensure` and `authorize` remain, including the epoch/binding and revocation-cutoff checks. Session-backed requests use only the gateway's session map under its mutex; idle and absolute expiry, logout and `RevokeSubject` remove access to subsequent requests. Conversation bodies and forwarded SSE frames no longer trigger broker exchanges. An admitted request or stream is not retroactively interrupted by logout or revocation. The existing conversation lease, per-socket UID checks and daemon response validation are unchanged for later removal steps.
