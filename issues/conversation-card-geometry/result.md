# Result

Full-width turn blocks now use the same column as the marker, recap and composer; the old `--ah-measure` cap no longer shortens tool rows and reply cards. A shared `--ah-card-inner-pad` token applies to the tool disclosure body and reply card. The older assistant-bubble rule had `padding-inline: 0` at higher specificity, which is why the reply looked flush even with a generic message padding; the override now reaches that rule. The Stop control centres its SVG via grid alignment. Output-box wrap controls are offered only when the unwrapped line exceeds the viewport; a ResizeObserver remeasures on width changes. The unwrapped lines are measured with the viewport font while wrapping is enabled, so the control can still undo wrapping. A full-gate browser run exposed a stale ResizeObserver callback after toggling wrap; the observer now recaptures the active wrapping state and text. The focused browser test passes after that fix. A later full-gate run exposed a test-only reload race: the saved edit disclosure could be replaced by native reconciliation between its click and diff assertion. The browser spec now waits for the saved history response and retries opening the disclosure if reconciliation remounts it; the focused spec passes. A later gate run still caught the disclosure briefly closing after a click, so the opening assertion now retries the action too rather than just polling the state.

Synthetic lab screenshots and static twins: `desktop.{png,html}` and `phone.{png,html}`. Both use the real browser/controller against fake Pi. `desktop-rectangles.json` measures marker, recap, composer, bash and reply at right 1234 px; `phone-rectangles.json` measures them at right 376 px. Both card interiors have 12 px horizontal padding. The Stop-square test measures centre offsets below 0.5 px. The phone capture checks content inside the available column. The draft uses one shared full-width column; deliberately unchanged are its global vertical spacing/density and different visual treatments of the recap and header, which belong to the separate prototype round. These captures do not exercise the real provider.

Checks: web static/unit/component focused check and host-backed `file-tool-cards.spec.ts` (desktop/phone rectangles, card inner padding and wrap-toggle resize), plus the Stop-square rectangle assertion in `lab-conversation.spec.ts`. Full clean gate is recorded in the worker report.
