# Prototype: account keys page (public SSH and age keys)

_Source: chat_

## Description

Prototype round for the account keys settings page (Jari 29.10., from `research-account-secrets`): shows the account's public SSH and age keys with fingerprint, copy button and a short "give this to your administrator" text, and creates a key when none exists (private half stays on the account, never shown). No secret browsing, no import, no recipient editing. Method as design-system/prototypes: 2–3 directions on one axis, production settings context, desktop and phone, light and dark, synthetic data, one offline file.
