# Pi session markers

The first native model and thinking entries merge into one row even when they arrive separately. Later changes and compaction share the same visual family; session names are suppressed. A settled thread has its work counts and fold in the head rather than a trailing summary. The duration is derived only when both the preceding native user timestamp and the thread's last native assistant timestamp exist and are valid; otherwise it stays unknown.

`lab-old-markers-phone-dark.{png,html}`, `lab-thread-light.{png,html}`, and `lab-thread-phone-dark.{png,html}` are paired synthetic-lab captures of the original UI. The old synthetic history only records a model change, not an initial thinking level. The synthetic new conversation has an assistant model but no initial settings marker; those native facts cannot be invented. Captures predate the duration contract: that fixture has no native message timestamps and therefore displays no invented duration. A focused unit test covers native timestamps versus missing facts; contracts, web, native-history and accessibility checks passed. The browser-conversation spec and clean gate are recorded at run closure.
